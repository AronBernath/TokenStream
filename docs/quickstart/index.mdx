# Quickstart

TokenStream sits behind client-facing applications and provides model routing, policy enforcement, retrieval, and ingestion. This page verifies the smallest local slice: start the runtime, discover an available model, and send one OpenAI-compatible chat completion request. It does not create a corpus or exercise retrieval.

## Prerequisites

Before starting, make sure you have:

- Access to a checkout that contains `docker-compose.yaml`
- Docker and Docker Compose
- At least one LLM provider API key
- For OpenAI-backed models: `OPENAI_API_KEY`
- For DeepSeek-backed models: `DEEPSEEK_API_KEY`
- A Hugging Face token only if your chosen embedding model is gated

The local Compose topology also references these values:

| Variable | Purpose |
| --- | --- |
| `MINIO_ROOT_USER` | MinIO object storage access key |
| `MINIO_ROOT_PASSWORD` | MinIO object storage secret key |
| `CONFIG_AUTH_INTERNAL_TOKEN` | Internal service authentication between registry, worker, retrieval, and orchestration services |
| `ORCHESTRATOR_RELOAD_TOKEN` | Runtime reload authorization for configuration changes |
| `RAG_OBJECT_STORAGE_BUCKET` | Object storage bucket name; Compose defaults to `rag-sources` |

Create or update `.env` in the repository root with the values required for your chosen provider and local storage setup.

<Warning>
The source material used for this page does not fully document the complete local startup command or every `.env` value. Start from your checkout's `docker-compose.yaml`. The variables listed here are the ones proven as required or referenced by the local Compose configuration.
</Warning>

## Steps

<Steps>
<Step title="Start the local stack">
Start the services defined in the repository `docker-compose.yaml`.

If your checkout uses the standard Docker Compose workflow, run:

```bash
docker compose up
```

</Step>

<Step title="Discover models">
Call the OpenAI-compatible models endpoint to confirm TokenStream is reachable and provider configuration has loaded.
</Step>

<Step title="Send a chat completion">
Send one small chat completion request through the orchestration API and confirm the response returns successfully.
</Step>
</Steps>
